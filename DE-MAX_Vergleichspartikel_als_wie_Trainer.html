Kada ide als, a kada so / genau so … wie?

ALS = različitost

Rečca als pokazuje da je nešto više ili manje u odnosu na nešto drugo. Pridev tada stoji u komparativu.

Mein Auto ist schneller als dein Auto.
Ich bin größer als mein Bruder.
Das Buch ist interessanter als der Film.
SO / GENAU SO … WIE = sličnost

Rečca so … wie ili genau so … wie pokazuje da su dve osobe ili stvari jednake. Pridev tada stoji u pozitivu.

Mein Auto ist genau so schnell wie dein Auto.
Ich bin so groß wie meine Schwester.
Der Kaffee ist so heiß wie die Suppe.
Zapamti: als = komparativ + različitost, a so / genau so … wie = pozitiv + sličnost.
